# Simple Button Flutter Example

A Flutter app demonstrating a basic interactive button UI pattern.

## Features

- **ElevatedButton**: The primary button style with elevation and background color
- **OutlinedButton**: A button with a border but no fill
- **TextButton**: A simple text-based button with no background

## Getting Started

1. Make sure you have Flutter installed on your system
2. Run `flutter pub get` to install dependencies
3. Run `flutter run` to start the app

## What it demonstrates

This example shows how to:
- Create different types of buttons in Flutter
- Handle button press events
- Update UI state when buttons are pressed
- Use basic Flutter widgets like `Scaffold`, `Column`, and `Text`

The app displays a counter that increments each time any button is pressed, demonstrating the interactive nature of the buttons.
